# oneStop-Quiz

A full-stack quiz application built with Node.js and Express that uses various AWS services. The project separates the user interface, backend services, and AWS Lambda logic to deliver a smooth quiz experience.

## Technology Stack

- Frontend: JavaScript-based web application
- Backend: Node.js and Express API service
- Cloud Services: Amazon EC2, Amazon DynamoDB, Amazon Cognito, and AWS Lambda
- Version Control: Git and GitHub

## Features

- Interactive quiz interface
- API-based communication between the frontend and backend
- Hosted on an Amazon EC2 instance
- Persistent data storage using Amazon DynamoDB
- User authentication using Amazon Cognito
- Serverless functionality using AWS Lambda
- Cloud-focused project structure suitable for AWS deployment

## Local Setup

This project cannot be fully cloned and run locally because it was developed and executed in a sandboxed AWS environment.
